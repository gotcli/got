# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities, exploit details, credentials,
or affected-user information in a public issue.

Use GitHub's private vulnerability reporting feature on the repository's
Security tab when it is available. If private reporting is unavailable, contact
a maintainer through a private contact method listed on their GitHub profile
and ask for a secure reporting channel without sending exploit details first.

Include the affected version, impact, reproduction steps, and any suggested
mitigation in the private report. Maintainers will acknowledge the report,
investigate it, and coordinate disclosure and remediation as appropriate.

General hardening suggestions that do not reveal an exploitable vulnerability
may be filed as public issues.
